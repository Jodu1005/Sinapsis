# 已归档频道设计

## 目标

让不再活跃的频道离开主频道列表，但保留其消息、Thread 和可恢复性。

## 用户体验

- 左侧导航将频道分成活跃“频道”和可折叠“已归档频道”文件夹；后者显示数量。
- 活跃频道可通过频道行操作归档；归档频道可打开查看历史，并可恢复。
- 已归档频道完全只读：不能发送消息、创建任务或触发 Agent。频道标题明确标记“已归档”。
- 只有关联任务均已结束（accepted、merged 或 cancelled）的频道可以归档。
- 恢复不会改变频道 ID、历史消息、Thread、订阅关系或任务关联。

## 服务契约

- Bootstrap 返回活跃与归档频道，并保留 `archivedAt`。
- `POST /api/channels/:channelId/archive` 将活跃频道写入 `archived_at`。
- `POST /api/channels/:channelId/restore` 清除 `archived_at`。
- 归档频道上所有消息写入和任务创建均返回领域错误。
- 活跃频道名称全局唯一；已归档频道不占用名称。恢复时若名称已被新的活跃频道占用，返回冲突错误。
- 归档和恢复发布 `channel.changed`，使已打开页面通过 SSE 刷新。

## 非目标

- 本次不做永久删除、批量归档、归档搜索或归档自动策略。
